# Security and support

## Reporting a security problem

If you think you've found a security vulnerability in MD Reader, **please don't open a public issue.** Email **founder@happie.in** instead, with:

- the MD Reader version and Windows version
- what you found and how to reproduce it
- what impact you think it has

You'll get a reply as soon as I can manage, and I'll keep you updated while it's fixed. Please give me a reasonable amount of time to ship a fix before you share details publicly.

Only the latest release receives security fixes.

## Support

- **Bugs:** open an issue at https://github.com/kunalsahu20/mdreader/issues
- **License keys, payments, lost key emails:** email founder@happie.in. Never post your license key in an issue.
- **Website:** https://mdreader.happie.in

## Getting MD Reader safely

Only download MD Reader from this repository's Releases page or from links on https://mdreader.happie.in. MD Reader isn't code-signed yet, so Windows SmartScreen may warn you the first time you run it. Click **More info**, then **Run anyway**.
